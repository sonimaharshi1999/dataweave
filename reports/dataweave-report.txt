======================================================================
  DataWeave - Declarative Data Pipeline Framework
======================================================================

Author: Maharshi Soni
Category: data-engineering
Difficulty: advanced

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
A pip-installable data pipeline framework with YAML-defined ETL workflows. Built-in operators for transform, validate, profile, and load data with HTML profiling reports.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - pandas
  - pydantic
  - pyyaml
  - click
  - jinja2
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * YAML-defined pipeline configuration
  * Built-in operators: filter, transform, aggregate, join, validate
  * Automatic schema inference
  * Data quality checks
  * HTML profiling report generation

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  CSV data and YAML pipeline config

  Example:
    dataweave run --pipeline pipeline.yaml --input data.csv

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Transformed data and quality report

  Example:
    dataweave profile --input data.csv --output report.html
